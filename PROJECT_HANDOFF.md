# Складно — памятка по проекту

Дата резервной копии: 6 августа 2026 года.

## Что это

Сайт для контроля остатков и движения товаров Wildberries:

- фактические остатки на складах WB;
- ручные остатки фулфилментов по артикулам;
- активные FBS-отгрузки;
- количество товара, которое перейдёт к продаже;
- выгрузка данных в CSV.

Ручные склады ФФ:

- Казань — Наш склад;
- Москва — БикПартнер;
- Питер — ФФ RUS СПБ.

Остаток на складах WB — это уже находящийся у Wildberries фактический сток. Он не считается доступным для FBS.

## Как запустить на другом компьютере

Нужны Git (если проект загружается из репозитория) и Node.js версии 22.13 или новее.

1. Распаковать резервную копию проекта.
2. Открыть терминал в папке проекта.
3. Выполнить:

   ```powershell
   npm install
   Copy-Item .env.example .env.local
   ```

4. Открыть `.env.local` и указать свой `WB_API_TOKEN`. Для локального входа также можно оставить `ADMIN_LOGIN=admin` и `ADMIN_PASSWORD=admin`. Значение `ADMIN_SESSION_SECRET` заменить длинной случайной строкой.
5. Запустить:

   ```powershell
   npm run dev
   ```

6. Открыть адрес, показанный в терминале.

Локальные ручные остатки ФФ хранятся отдельно от опубликованного сайта. Данные опубликованного сайта находятся в его базе D1.

## Где что находится

- `app/page.tsx` — интерфейс дашборда;
- `app/api/inventory/route.ts` — получение остатков и FBS из API WB;
- `app/api/ff-stock/route.ts` — сохранение ручных остатков ФФ;
- `app/api/auth/` и `lib/admin-auth.ts` — вход в админку и сессия;
- `db/` и `drizzle/` — таблицы и миграции базы данных;
- `.openai/hosting.json` — привязка проекта к опубликованному сайту.

## Важное о безопасности

Токен WB, секрет сессии и другие значения из `.env.local` не входят в резервный ZIP и не хранятся в Git. В опубликованной версии они находятся в защищённых переменных окружения Sites.

## Как продолжить работу с Codex завтра

На другом компьютере войти в тот же аккаунт Codex, открыть эту же задачу и написать: «Продолжаем Складно». История задачи сохранит контекст. Если открыть совершенно новую задачу, приложить этот файл и ZIP проекта — по ним можно быстро восстановить весь контекст.
